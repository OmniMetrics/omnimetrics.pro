# OmniMetrics Website (Vue + Vite + Tailwind)

This repo hosts the OmniMetrics marketing site, built with **Vue 3**, **Vite**, and **TailwindCSS**.

## Quickstart

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Site structure

- `/` — Home
- `/solutions` — Solutions overview
- `/solutions/coach` — AI Coach Assistant
- `/solutions/broadcast` — AI Broadcast Assistant
- `/platform` — OmniMetrics Engine (platform)
- `/company` — Company

## Domain

`public/CNAME` is kept for GitHub Pages / custom domain usage.
